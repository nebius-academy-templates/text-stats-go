# Course submission guidance

- Keep the exercise's investigation, review, or documentation lookup read-only.
- Only when the learner explicitly requests the final submission export, read [OUTPUT.md](OUTPUT.md) and write `report.json` in the specified format.
- OUTPUT.md describes serialization, not an answer key or permission to change the application. Do not read it to seed an independent review.
- Use observed results. Ask the learner for missing observations, especially checks performed outside this chat; never invent tool calls, findings, approvals, or test results.
- Do not commit or push. The learner verifies the report and submits it.
